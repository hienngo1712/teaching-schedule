# Nâng Node.js 20 → 24 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps dùng checkbox (`- [ ]`).

**Goal:** Đổi `engines.node` từ `20.x` sang `24.x` trước **01/10/2026**. Sau ngày đó Vercel không build được bản deploy nào còn khai báo Node 20.

**Architecture:** Chỉ đổi môi trường chạy, không đổi code nghiệp vụ. Rủi ro nằm ở các gói có binary gắn với phiên bản Node, chủ yếu là Prisma 5 (query engine).

**Tech Stack:** Next.js 15.5.25, React 19.3.0, Prisma 5.22, vitest 4, Playwright. Vercel + Neon.

## Global Constraints

- Làm trên nhánh mới từ `main`, không commit thẳng `main`.
- **CẤM sửa** `src/server/services/`, `src/server/trpc/routers/`, `prisma/`. **CẤM tạo migration.**
- **CẤM đổi** `build` script: phải giữ `prisma generate && prisma migrate deploy && next build`.
- **Chỉ chạy MỘT tiến trình vitest tại một thời điểm** (DB test dùng chung, chạy song song ra lỗi FK `P2003` giả).
- **KHÔNG** chạy `prisma migrate reset`, `db push --force-reset`, `pnpm db:reset`. Trước lệnh đụng DB: đọc `docs/coding-rule.md` §6.1.
- **KHÔNG** in toàn bộ `DATABASE_URL` (chứa mật khẩu). Chỉ trích host: `sed -E 's|.*@([^/]+)/.*|host=\1|'`.
- Playwright: trước mỗi lần chạy phải thấy `import './tests/env-setup'` ở đầu `playwright.config.ts`.
- Comment tiếng Việt, tối đa 1–2 dòng, chỉ ghi lý do không hiển nhiên.
- Mốc hiện tại: 38 file / 274 test vitest xanh, `tsc` sạch, lint 0 error / 29 warning, `next build` xanh.

## Bối cảnh

- `package.json`: `"engines": { "node": "20.x" }`, `"@types/node": "^20"`.
- Máy dev đang chạy **Node 22.18** → toàn bộ test hiện có mới chỉ chứng minh chạy được trên 22, **chưa ai chạy trên 24**.
- Vercel báo khi build: `Node.js version 20.x is deprecated. Deployments created on or after 2026-10-01 will fail to build. Please set "engines": { "node": "24.x" }`.
- Gói cần để ý: `prisma`/`@prisma/client` 5.22 (binary engine), `sharp` (optional dep của next, native), `bcryptjs` (JS thuần, không lo).
- `prisma/schema.prisma` không khai báo `binaryTargets` → Prisma tự chọn engine theo môi trường build.

## Phương án dự phòng (quyết định trước khi làm)

Nếu Task 2 thấy Prisma 5 không chạy trên Node 24: **dừng, báo lại**, KHÔNG tự ý nâng Prisma 6 (Prisma 6 là major có đụng schema/migration, phải có plan riêng). Phương án tạm là đặt `22.x` — đã được chứng minh qua toàn bộ test trên máy dev. Kiểm trước tại https://vercel.com/docs/functions/runtimes/node-js/node-js-versions rằng Vercel còn hỗ trợ 22.x.

### Task 1: Cài Node 24 ở máy dev

- [ ] **Step 1:** Cài Node 24 song song bằng trình quản lý phiên bản (vd `nvm-windows`: `nvm install 24` rồi `nvm use 24`). Không gỡ Node 22.
- [ ] **Step 2:** `node --version` → phải ra `v24.x`.
- [ ] **Step 3:** `npx pnpm install` (cài lại để các gói native build cho Node 24).

Expected: cài xong không lỗi. Nếu `sharp` hay `@prisma/engines` báo lỗi build → ghi nguyên văn, **dừng và báo**.

### Task 2: Kiểm Prisma trên Node 24 (bước rủi ro nhất)

- [ ] **Step 1:** `npx prisma generate` → phải xanh.
- [ ] **Step 2:** `npx prisma --version` → ghi lại dòng `Query Engine` và `Node.js`.
- [ ] **Step 3:** Chạy riêng một test integration nhẹ để chứng minh Prisma nói chuyện được với DB test:
  `npx vitest run tests/integration/health.test.ts`
  Expected: xanh. Đỏ → dán lỗi, dừng, áp phương án dự phòng.

### Task 3: Đổi khai báo và chạy toàn bộ kiểm chứng

**Files:** `package.json`, `pnpm-lock.yaml`

- [ ] **Step 1:** Trong `package.json` đổi `"node": "20.x"` → `"node": "24.x"`.
- [ ] **Step 2:** `npx pnpm add -D @types/node@^24` (cho kiểu khớp runtime). Kiểm lại `package.json` đúng `^24`, không có gói nào khác bị đổi version ngoài ý muốn (`git diff package.json`).
- [ ] **Step 3:** `npx tsc --noEmit` → sạch. Nếu `@types/node` 24 gây lỗi kiểu thì chỉ sửa đúng dòng báo lỗi.
- [ ] **Step 4:** `npx pnpm lint` → 0 error.
- [ ] **Step 5:** `npx next build` → `✓ Compiled successfully`, 12/12 trang.
- [ ] **Step 6:** `npx vitest run` (khoảng 14 phút, chạy nền và chờ đủ). Expected: **38 file / 274 test xanh**, bằng mốc.
- [ ] **Step 7:** `npx playwright test`. Expected: `auth` 3/3, `students` 1/1 xanh; `upgrade-class` skip; `calendar` đỏ là **lỗi cũ đã biết** (test tìm `input[type="time"]` nhưng app dùng `TimeInput`), không tính là regression.
- [ ] **Step 8:** Commit:

### Task 4: Deploy (người dùng làm, cần xác nhận)

- [ ] **Step 1:** Push nhánh, merge vào `main`, push `main`.
- [ ] **Step 2:** Trong log build Vercel phải thấy Node 24 và **không còn** cảnh báo `Node.js version 20.x is deprecated`.
- [ ] **Step 3:** `prisma migrate deploy` trong log phải in "No pending migrations".
- [ ] **Step 4:** Kiểm nhanh production: đăng nhập, mở Báo cáo tháng hiện tại, số học phí khớp với trước deploy.

## Rollback
